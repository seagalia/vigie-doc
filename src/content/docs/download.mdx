Vigie is one static binary with no dependency. Each archive holds the `vigie` binary and the README of the project. [Install Vigie](/start/install/) shows how to check an archive and run the binary as a service.

## Other ways to get Vigie

- **Build it yourself**: clone the [repository](https://github.com/seagalia/vigie) and run `CGO_ENABLED=0 go build .`, as in
  the [quickstart](/start/quickstart/#build-the-vigie-binary).
- **Container image**: no image is published yet. `make docker` builds one from the repository, see
  [Run in a container](/start/install/#run-in-a-container).
